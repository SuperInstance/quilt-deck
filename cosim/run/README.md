cosim/run/ is a pure-artifact directory: empty until a run, everything
regenerated by deck/cosim.py at run time. No outputs are kept without
their provenance inputs (position (a), EXPERT nudge re 775446d — an
egress file without the .ops that produced it is an effect without its
cause). The one exception to deletion-forever: if a timed-out fpga sim
leaves PARTIAL egress, copy it out with its .ops pair before the next
run overwrites it — that pair is the incremental-$fflush evidence.
